## 📌 Project Overview

This project was developed using **IBM Cognos Analytics** to analyze automobile sales, recalls, customer sentiment, and dealership performance through interactive dashboards and business visualizations.

The dashboard provides insights into vehicle recalls, monthly sales trends, profit analysis, and affected automobile systems using the Auto Group dataset.

---

## 📊 Dashboard Features

The dashboard includes the following visualizations and KPI metrics:

- Number of recalls by vehicle model
- Customer sentiment analysis (Positive, Neutral, Negative)
- Profit and quantity sold by month
- Recalls by affected system and model (Heat Map)
- Interactive business visualizations
- Trend analysis dashboards
